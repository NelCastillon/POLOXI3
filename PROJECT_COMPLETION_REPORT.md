## 📋 DATABASE DETAILS

### Schema: Agency

#### Profile Table
```
- ProfileId (PK)
- TenantId
- LegalName, DBA, FederalTaxId
- ContactFirstName, ContactLastName, ContactEmail, ContactPhone
- StreetAddress, City, State, ZipCode
- EoCarrier, EoPolicyNumber, EoExpiryDate, EoCoverageAmount
- Audit columns (Created/Modified)
```

#### Branch Table
```
- BranchId (PK)
- TenantId
- BranchName, BranchCode (unique)
- StreetAddress, City, State, ZipCode
- Phone, Fax, Email
- ManagerUserId, ManagerName
- IsActive, IsHeadquarters
- Audit columns
```

#### Department Table
```
- DepartmentId (PK)
- TenantId, BranchId (FK)
- DepartmentName, DepartmentCode, Description
- ManagerUserId, ManagerName
- IsActive
- Audit columns
```

#### Team Table
```
- TeamId (PK)
- TenantId, DepartmentId (FK)
- TeamName, TeamCode, Description
- ManagerUserId, ManagerName
- TeamType, MemberCount
- IsActive
- Audit columns
```

#### Staff Table
```
- StaffId (PK)
- TenantId, UserId, BranchId (FK)
- FirstName, LastName, Email, Phone
- Title, Role, Department, Team
- LicenseType, LicenseNumber, LicenseStates
- LicenseExpiryDate, LicenseRenewalDate
- AppointedCarriers, CommissionRate
- IsActive, EmploymentStatus
- HireDate, TerminationDate
- Audit columns
```

### Indexes
- IX_Profile_TenantId
- IX_Branch_TenantId, IX_Branch_Code
- IX_Department_TenantId, IX_Department_BranchId
- IX_Team_TenantId, IX_Team_DepartmentId
- IX_Staff_TenantId, IX_Staff_LicenseNumber, IX_Staff_LicenseExpiry, IX_Staff_Role
