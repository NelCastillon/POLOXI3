## Recording workflow

1. Wire a live `IIntelligenceWideService` in `WideBaselineRecordingTests.CreateLiveService()`.
2. Set env vars: `POLOXI_BASELINE_RECORD=1`, `POLOXI_BASELINE_TENANT`, `POLOXI_BASELINE_USER`,
   `POLOXI_BASELINE_DIR` (point at this folder).
3. Run the single recorder test; commit the generated `*.json`.

Normal unit/CI runs skip the recorder (no DB, no network).
