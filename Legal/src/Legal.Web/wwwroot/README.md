# Judz.ai Enterprise Website

Static, production-style landing site. No build tools required.

## Run
Open `index.html` directly, or serve the folder locally:

```bash
python3 -m http.server 8080
```

Then visit http://localhost:8080

## Structure
- index.html — site content
- styles.css — responsive enterprise styling
- app.js — navigation behavior
- assets/judz-hero.png — main Judz.ai banner artwork
