## 🆘 Issues?

### PowerShell "Module not found"
```powershell
Install-Module -Name SqlServer -Force
```

### "Access Denied"
- Run PowerShell as Administrator

### "Connection Failed"
- Check server name is correct (usually `localhost` for local SQL Server)
- Verify SQL Server is running

### "Table already exists"
- That's ok! Script won't create duplicates
- Safe to run again
